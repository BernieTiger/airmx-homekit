# 秒新 AirMX 加湿器 · 本地化 HomeKit 接入

秒新（AirMX）已经停止运营，官方 App 和云端服务都关掉了。加湿器本身没坏，但没有服务器就连不上，也控制不了。

这个项目在本机重建了这条链路：设备照常工作，还能接进 Apple 家庭，用 Siri 和自动化控制。

---

## 背景

秒新停运之后，AirWater A3 / A3S / A5 这些机器处在一个尴尬的状态：

- 硬件是好的。风机、水泵、雾化、温湿度传感器、水位检测都能正常工作
- 软件没法用。App 打不开，云端通道没了，远程控制和自动化全部失效
- 机身上只剩几个按键，能开关机、切档位，别的做不了

这些机器当年卖得不便宜，加湿效果放到现在也够用。因为厂家没了就当废品处理，有点浪费。它们其实不缺功能，缺的是一条能用的控制通道。

---

## 做了什么

把原来依赖厂商云的部分搬到本地，分成四段：

```
设备  ──DNS 劫持──>  本地网关  ──MQTT──>  bridge  ──HTTP──>  HomeKit 桥接  ──> 家庭 App
```

1. **DNS 劫持**：让设备把 `*.airmx.cn` 解析到你的局域网地址。设备以为还在连官方服务器，照常工作
2. **本地网关**：复现设备侧的注册、心跳和指令签名，让设备愿意接受指令
3. **HomeKit 桥接**：把设备能力翻译成 Apple 家庭能理解的语义，用 Siri 和自动化控制

整个过程不需要外部服务，局域网内就能跑，数据不经过第三方。

---

## 适合谁

**适合**

- 手里有秒新加湿器，官方 App 已经用不了的
- 想把它接进 Apple 家庭，做定时、联动、语音控制的
- 愿意折腾一次，换长期可用的

**不适合**

- 想在外网远程控制。需要自己搭内网穿透，不在本项目范围内
- 想找一个云端替代品。本项目不提供任何托管服务
- 想刷机改固件。设备一个字节都不会动，也不需要

## 快速开始

### 需要准备

1. 一台常年开着的机器（NAS、树莓派或 Linux 主机），装好 Docker 和 Compose 插件
2. 路由器的管理权限，用来改 DNS
3. 加湿器和这台机器在同一个局域网

### 三步

```bash
# 1. 下载
git clone https://github.com/BernieTiger/airmx-homekit.git
cd airmx-homekit

# 2. 生成配置：随机 token、secrets、.env
./scripts/bootstrap.sh

# 3. 启动
docker compose -f deploy/compose.yaml up -d
```

启动之后还有两件事必须做，否则设备不会连过来：

4. 在路由器上把 `*.airmx.cn` 指向这台机器的 IP，做法见 [docs/03-部署指南.md](docs/03-部署指南.md)
5. 家庭 App 里添加配件，输入 `.env` 里的配对码

每一步的验收标准都写在 [docs/03-部署指南.md](docs/03-部署指南.md)。动手之前建议先读 [docs/01-逆向排查思路.md](docs/01-逆向排查思路.md)，里面解释了为什么必须做 DNS 劫持。
